## PalCMS 1.0.0: first release

PalCMS is a free, open-source (MIT) website + admin panel for Palworld dedicated servers. One command on a VPS installs the site; the site then installs the game server, or connects to the one you already have.

### Public website for your players
- Live map: players, points of interest, guild bases, fast travel points and boss towers
- Leaderboard (level, playtime, seniority, buildings) and player profiles with charts
- Guilds, server Paldex (all 288 Pals, per server, player and guild), events calendar, uptime page
- News, pages, editable menu, light / dark theme
- Player accounts (Steam or email) showing their Pals, inventory and guild; reports and suggestions

### Admin panel
- Start / stop / restart, `PalWorldSettings.ini` editor, presets and temporary events (e.g. XP x3 weekend)
- Monitoring with alerts, 30-day history, attendance statistics
- World data from the save files: inventories, Pals, guilds, item search
- Live logs, automatic backups with restore, scheduled restarts with announcements, automatic server updates
- Moderation, warnings, temporary bans, light anti-cheat, RCON console, Discord notifications
- Team roles and audit log, one-click PalCMS updates

### Connect an existing server
Already running Palworld? Connect it through its REST API, no reinstall needed.

### Install
Ubuntu 22.04 / 24.04 (x86_64):

```bash
curl -fsSL https://github.com/Flowbric-Git/palcms/releases/latest/download/install.sh | sudo bash
```
