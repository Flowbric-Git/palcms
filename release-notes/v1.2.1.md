## PalCMS 1.2.1: fix for the audit log page

PalCMS is a free, open-source (MIT) website + admin panel for Palworld dedicated servers.

### Fixes
- **Leaving the audit log page could crash the admin panel** ("destroy is not a function") in recent browsers, where scrolling returns a Promise. The RCON console had the same issue since 1.1.x. Both are fixed.

Everything new in 1.2.0 (locked theme menu links, drop-down side menu, always-dark panel) is described in the [1.2.0 notes](https://github.com/Flowbric-Git/palcms/releases/tag/v1.2.0).

### Install or update
Update from the panel (*Updates*, or *Mises à jour* on a French site), or install on Ubuntu 22.04 / 24.04:

```bash
curl -fsSL https://github.com/Flowbric-Git/palcms/releases/latest/download/install.sh | sudo bash
```
