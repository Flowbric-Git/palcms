## PalCMS 1.1.1: live Paldex and profiles

PalCMS is a free, open-source (MIT) website + admin panel for Palworld dedicated servers.

### Improved: world data follows the game
- **Live read while players are online**: the world save is read every 30 seconds, so Pals you catch show up in the server Paldex and in your profile (*My Pals and inventory*) within a minute, instead of up to 15 minutes later.
- The live read uses the server's own autosave (no extra forced save) and spaces itself out automatically on big worlds to keep the CPU free. It can be turned off in *Server > World data*. When nobody plays, the usual interval applies.
- **Pages refresh on their own**: the profile, the Paldex and the guilds page update every 30 seconds while they are open (paused when the tab is hidden).

### Fixes
- A save character without a name showed "Inconnu" instead of "Unknown".

### Install or update
Update from the panel (*Updates*, or *Mises à jour* on a French site), or install on Ubuntu 22.04 / 24.04:

```bash
curl -fsSL https://github.com/Flowbric-Git/palcms/releases/latest/download/install.sh | sudo bash
```

## PalCMS 1.1.1 : Paldex et profils en direct

PalCMS est un CMS gratuit et open source (MIT) pour serveurs dédiés Palworld : site public et panel d’administration.

### Amélioré : les données du monde suivent la partie
- **Lecture en direct pendant que des joueurs sont connectés** : la sauvegarde du monde est lue toutes les 30 secondes. Les Pals capturés apparaissent dans le Paldex du serveur et dans ton profil (*Mes Pals et mon inventaire*) en moins d’une minute, au lieu de jusqu’à 15 minutes plus tard.
- La lecture en direct utilise la sauvegarde automatique du serveur (aucune sauvegarde forcée en plus) et s’espace toute seule sur les gros mondes pour laisser le processeur libre. Elle se désactive dans *Serveur > Données du monde*. Quand personne ne joue, l’intervalle habituel s’applique.
- **Les pages se mettent à jour toutes seules** : le profil, le Paldex et la page des guildes se rafraîchissent toutes les 30 secondes tant qu’ils sont ouverts (en pause quand l’onglet est caché).

### Corrections
- Un personnage sans nom dans la sauvegarde s’affichait « Inconnu » au lieu de « Unknown » sur un site en anglais.

### Installer ou mettre à jour
Mise à jour depuis le panel (*Mises à jour*), ou installation sur Ubuntu 22.04 / 24.04 :

```bash
curl -fsSL https://github.com/Flowbric-Git/palcms/releases/latest/download/install.sh | sudo bash
```
