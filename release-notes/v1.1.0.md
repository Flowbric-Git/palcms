## PalCMS 1.1.0: English by default, French available

PalCMS is a free, open-source (MIT) website + admin panel for Palworld dedicated servers.

### New: English and French
- **English by default**: setup wizard, public site, admin panel, error messages, Discord notifications and in-game announcements.
- **Full French translation**: pick the site language in the setup wizard or later in *Website > Appearance*. Every visitor can also switch with the **EN / FR** button.
- **English addresses** (`/news`, `/leaderboard`, `/map`, `/events`, `/admin/server/…`). Old French links keep working and redirect.
- **Existing sites stay in French** after the update, with their menu converted automatically. Switch the language whenever you like.
- **"Join the server" button link** is now a setting (*Website > Appearance*).

### Extensions
- `lang()` and `t()` in `@palcms/sdk`: extensions can follow the visitor's language and reuse PalCMS translations.
- The example plugin (Announcement banner) and theme (Aurora) are in English with French texts. Aurora 1.1.0 needs PalCMS 1.1.0 (new addresses).

### Fixes
- Event changes ("Experience rate: x3") are shown in the visitor's language.
- A few server error messages were not translated.

### Install or update
Update from the panel (*Updates*, or *Mises à jour* on a French site), or install on Ubuntu 22.04 / 24.04:

```bash
curl -fsSL https://github.com/Flowbric-Git/palcms/releases/latest/download/install.sh | sudo bash
```
