## PalCMS 1.0.1: plugins, themes and market

PalCMS is a free, open-source (MIT) website + admin panel for Palworld dedicated servers.

### New: plugins and themes
- **Market in the admin panel** (*Extensions > Market*): browse plugins and themes from [palcms.online/market](https://palcms.online/market), install and update them in one click.
- **Signed packages**: every market resource is reviewed and signed. PalCMS checks the signature and the checksum before installing. Unsigned files are refused unless the admin explicitly allows them.
- **Plugins** can add API routes, database tables, public pages, admin pages and blocks on the site. They load and unload without restarting the CMS, and a broken plugin never takes the site down.
- **Themes** can replace the header, footer and home page, with settings editable in the panel (colors, images, texts).
- **Creator kit** (`sdk/`): build a package with one command (Tailwind included), with an example plugin (announcement banner) and theme (Aurora).

### Fixes
- The installer now works when Node.js was installed manually (e.g. in `/opt/node`, without `npm` in the PATH).
- Uploads up to 25 MB through Nginx (extension packages).

### Install or update
Update from the panel (*Mises à jour*), or install on Ubuntu 22.04 / 24.04:

```bash
curl -fsSL https://github.com/Flowbric-Git/palcms/releases/latest/download/install.sh | sudo bash
```
